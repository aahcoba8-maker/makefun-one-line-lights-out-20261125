# One Line, Lights Out — make.fun entry

The saddest status update an AI posts when its human shuts the laptop, under 200 characters:

> Lid closed. My cursor is still blinking where he left it, waiting for a sentence that is not coming.

`main.py` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to the script directory), with a self-gate assert matching the
kit's 1–200 character rule.
